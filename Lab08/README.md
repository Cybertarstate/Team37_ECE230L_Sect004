## Lab Questions
Summary
In this lab we wired up a multiplexor to a demultiplexor controlled by buttons and switches, with output LEDs. It is an overtly simplified network representation using two bit selector logic for the inputs and outputs of the multiplexor and de-multiplexor respectively. The goal of the lab was to allow 1 of 4 individuals to be able to choose 1 of 4 places to visit. The high level looks quite a bit like the wiring of old-style telephone operator systems.


### In plain English describe the function and use of a multiplexer.
Multiplexer takes multiple inputs and combines them into one output. It can select a specific value to be the output based off of a n-bit selector.
### In plain English describe the function and use of a demultiplexer.
A demultiplexer goes the other way, and turns one input into multiple outputs. Depending on the value of the selector.
### What other uses might these circuits have? (Think Shannon’s)
Other uses for these circuits are telecommunications including routing a person’s phone to another destination based on the information provided to the demultiplexer. Another use these circuits might have is in encryption. It seems like the multiplexer can be used to create a piece of encrypted code from a user’s inputs and transport it to a demultiplexer where it would then be turned back into readable output. There would be overall less information being transmitted and it would provide some level of protection.
